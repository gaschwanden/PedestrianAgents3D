# PedestrianAgents3D

3D Multitouch Pedestrian Agents in Java.

This project uses [Processing](https://processing.org/) and the [TUIO](https://www.tuio.org/)
protocol as an environment and extends the work from Eva-Maria Friedrich at FCL.

The application loads a site (buildings, obstacles, streets and a waterbody) from
DXF files in `text/`, renders it as an interactive 3D scene with OpenGL (via JOGL),
and simulates pedestrian agents that can be released and analysed through the
on-screen (multitouch/mouse) interface.

## Project layout

| Path | Description |
| --- | --- |
| `src/` | Java sources. Entry point: `Agents` (extends Processing's `PApplet`). |
| `library/` | Bundled dependencies: Processing `core.jar`, JOGL 2.1.5, GlueGen, TUIO, plus platform native libraries. |
| `data/` | Pre-baked Processing fonts (`.vlw`). |
| `text/` | Site geometry (DXF) and origin/destination definitions. |
| `scripts/` | Build / run helper scripts (see below). |
| `bin/` | Compiled classes (generated by the build; git-ignored). |

## Requirements

- A JDK (tested with OpenJDK 21).
- OpenGL 2.0+. On a machine with a GPU the bundled JOGL natives are used directly.
  On a headless Linux host, software OpenGL (Mesa `llvmpipe`) under a virtual X
  display (`Xvfb`) works fine.

Native JOGL/GlueGen libraries are bundled for macOS (`*-natives-macosx-universal.jar`)
and Linux x86-64 (`*-natives-linux-amd64.jar`). The run script selects the correct
set automatically based on the host platform.

## Build

```bash
bash scripts/build.sh
```

This compiles everything in `src/` to `bin/` using the jars in `library/`.

## Run

```bash
# On a machine with a display:
bash scripts/run.sh

# On a headless machine, first start a virtual display with software OpenGL:
bash scripts/start-display.sh   # starts Xvfb on :99
DISPLAY=:99 bash scripts/run.sh
```

> Note: the sketch derives its data folder from the process working directory
> (it expects to be launched from `bin/`). `scripts/run.sh` handles this
> automatically, so always launch via the script rather than invoking `java`
> directly.

The application starts in Processing's full-screen "present" mode. Loading the
DXF geometry takes several seconds; once loaded the 3D site is drawn together
with the red interaction-button grid in the top-left corner.

### Controls (mouse)

- `SHIFT` + drag — rotate the scene (tilt into 3D).
- `CTRL` + drag — zoom in / out.
- `SPACE` + drag — pan.
- `r` — reset the view.
- `m` — toggle between mouse and TUIO input.

## Cloud Agent environment

`.cursor/environment.json` wires the above scripts into the Cloud Agent lifecycle:

- `install` → `scripts/build.sh` (compile).
- `start` → `scripts/start-display.sh` (bring up the `Xvfb :99` software-OpenGL display).
- `terminals` → runs `scripts/run.sh` on `DISPLAY=:99`.

To capture the running app on a headless host you can screenshot the virtual
display, e.g. `DISPLAY=:99 import -window root scene.png` (ImageMagick) or record
it with `ffmpeg -f x11grab -i :99 ...`.
